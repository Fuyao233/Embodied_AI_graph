# Demystifying Action Space Design for Robotic Manipulation Policies

## Navigation
- Paper note: [Demystifying Action Space Design for Robotic Manipulation Policies note](../notes/动作空间设计-note.md)

## Core Insight

- 时间抽象至关重要——在采用恰当的现代技术手段时，无论在何种学习范式下，基于增量的动作表征表现均始终优于绝对动作表征
- 空间抽象则取决于具体场景——关节空间控制在数据充足、训练充分且模型能力强大的标准场景下表现卓越，而任务空间表征则在跨具身和迁移学习等泛化场景中展现出更优越的性能
- action chunk的设计：
  - chunk-wise delta > step-wise delta
  - action chunk的长度选择和空间抽象是耦合的，绝对控制受益于长action chunk而相对控制则在较短的action chunk下达到效果峰值
