## Core Insight
最大的亮点就是open-world generalization 的训练配方以及subgoal的规划：多机器人数据、跨 embodiment 数据、web 多模态数据、目标检测/定位、高层 subtask prediction、verbal instruction，以及低层连续动作被放进同一个 co-training 框架

- 用flow matching做动作头之前就有（GR00T）
- KV cache 拼接也是pi0就有
- 外挂 expert 也是之前就有

在泛化方面做出的贡献：

| 泛化层级              | π0.5 的处理方式                                                       | 解决的问题                          |
| ----------------- | ---------------------------------------------------------------- | ------------------------------ |
| **视觉/物体泛化**       | 引入 web data、object detection、captioning、VQA                      | 认识没在机器人数据中大量出现过的新物体类别          |
| **环境泛化**          | 多环境机器人数据，尤其是不同家庭/不同布置                                            | 不依赖固定厨房、固定卧室、固定背景              |
| **任务结构泛化**        | subtask prediction、verbal instruction、high-level semantic action | 长任务中知道下一步该做什么，比如先拿枕头、再铺床、再整理衣物 |
| **embodiment 泛化** | cross-embodiment robot data                                      | 从不同机器人和不同数据源迁移行为模式             |
