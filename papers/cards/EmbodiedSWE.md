# EmbodiedSWE: Coding Agents for Long Horizon Dexterous Robotics

## Navigation
- Paper note: [EmbodiedSWE: Coding Agents for Long Horizon Dexterous Robotics note](../notes/EmbodiedSWE-note.md)

## Core Insight

Coding Agent → 编写机器人控制/规划代码 → 仿真执行 → 反馈 → 修改代码 → 得到可执行解法



类似工作：

- SimEX: Simulation-Integrated Robotics AutoResearch
- Coding Agents for Generalized Task and Motion Planning Problems



此类工作主要是研究如何利用 coding agent 系统生成仿真数据的，思路类似



目前仿真数据主要用于预训练



本篇工作的思路是围绕 coding agent 得到的一个强解进行增广，得到大量学生数据，如果能探索不同强解就好了
