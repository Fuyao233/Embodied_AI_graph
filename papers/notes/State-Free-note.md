# Do You Need Proprioceptive States in Visuomotor Policies? Note

## Navigation
- Paper card: [Do You Need Proprioceptive States in Visuomotor Policies? card](../cards/State-Free.md)

## Reading Notes

这篇研究提出一种**"无状态策略"（State-free Policies）**，核心观点是：**在视觉运动策略中彻底去掉本体感觉状态输入（如末端执行器位姿、关节角度），仅依赖视觉观测来提升机器人的空间泛化能力。**

**为什么要这么做**

- 当前视觉运动策略普遍同时使用视觉 + 状态输入
- 状态输入虽提供精确的机器人构型信息，但容易让策略 "死记硬背" 训练轨迹 → 过拟合
- 一旦演示数据中物体位置覆盖范围不够广，空间泛化能力就严重受限
- 而采集覆盖广泛状态的演示数据成本极高，成为部署瓶颈

**实现的两个关键条件**

1. **相对末端执行器动作空间**—— 只预测末端执行器的相对位移，天然利于泛化
2. **完整任务观测**—— 通过末端执行器上下各装一个广角腕部相机（约 120°×120°），保证 "看全" 任务相关物体



**三大优势（对比基于状态的策略）**

表格

| 优势       | 说明                                                         |
| ---------- | ------------------------------------------------------------ |
| 空间泛化   | 不依赖状态 → 不记忆轨迹 → 对物体在高度 / 水平方向上的位置变化泛化能力强 |
| 数据效率   | 摆脱了对轨迹多样性的依赖，可用更少演示数据微调，降低采集成本 |
| 跨本体适应 | 只依赖视觉 + 相对动作空间，无需适配不同状态空间，可快速迁移到新机器人 |





本文用 delta EEF 的原因主要是 state-free 的选择。模型看到画面判断要移动 $\Delta x$，对于 joint space 这个移动必须是根据当前关节角才能知道为了实现这个变化各关节要怎么变，缺失了本体信息会导致歧义。
