# 记忆相关的Insight

- 必须建模记忆的场景：本质上因为标准VLA是一步马尔可夫过程
  - 有长时间等待，比如做饭
  - 有重复情景，导致阶段误判
- 训练的时候往往是成功序列，但是inference的时候可能会有重复的失败任务，因为会导致分布的漂移
- 向量记忆的缺点是“不可解释”且容易在长时间尺度下产生漂移（Drift）或被噪声淹没



短期记忆解决的几类具体问题：

- 遮挡/自遮挡（长时也会遇到）
- 精细操作中的动态连续性：抓取、推、翻、擦、舀这类动作依赖最近几帧的运动趋势，而不是单帧语义
- 失败后的即时策略调整： 没有短期记忆时，模型不知道刚才怎么失败的，容易重复同一个错误
- 进度追踪（长时也有）





## Evidence
- 预训练阶段发展出 memory capability，比只在 post-training 加记忆效果好很多。—— pi-mem
