# 训练对部署参数的影响



### Training-RTC

- 对推理延迟：要求在训练时采样范围内

  



## RLT

- 对 replan step：推理的时候 replan step + 推理延迟 要等于训练时候的 C，因为 critic model 计算的就是 C 步之后的价值，拿 C 步的动作块当 RL 的一步

![image-20260730153549735](训练对部署参数的影响.assets/image-20260730153549735.png)

| 数学符号 | 代码变量名                       | 含义                                                |
| -------- | -------------------------------- | --------------------------------------------------- |
| (r)      | `self.config.async_replan_steps` | 新 chunk 安装后，需要实际发送多少帧才触发下一次推理 |
| (d)      | `elapsed`                        | 本次推理期间，发送线程实际发送的动作帧数            |
